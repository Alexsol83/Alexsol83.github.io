STEAM BIG PICTURE BY KOVROV TEAM
ПУБЛИЧНАЯ ИНСТРУКЦИЯ ПО ПОДГОТОВКЕ

This device-neutral checklist prepares Steam and a controller before you apply
the project's Windows setup kit. Steam menu names may differ by version and
language.

1. Start Steam and sign in
Install Steam, sign in, and launch it at least once. Keep the Steam client
running in Windows; it can remain minimized in the notification area.

2. Connect and check the controller
Connect your controller and confirm Steam detects it under Steam > Settings >
Controller. Enable support for the matching controller type if needed. For the
Guide/Home button flow, enable Guide Button Focuses Steam when available.

3. Choose the TV as the preferred Big Picture display
Open Big Picture and go to Steam menu > Settings > Display > Preferred Display.
Select your TV from the list. Display numbers can change after reconnecting
screens, so use the device name rather than relying on a fixed number.

Steam may apply the preferred display on the next Big Picture launch. Exit and
open Big Picture again to verify the selection.

4. Optional: start Steam with Windows
If you want to sign in to Windows and then open Big Picture from the controller,
enable Run Steam when my computer starts in Steam's Interface settings. Wait
for Steam to finish starting before pressing Guide/Home.

5. Keep automatic Big Picture startup off for this flow
For the controller-first sequence, Steam should start as its regular desktop
client; the controller opens Big Picture afterward. Leave any setting that
launches directly into Big Picture disabled for this scenario.

6. Test entry and exit
Start Steam normally and press the controller's Guide/Home button. To exit, use
the Big Picture power menu and choose Exit Big Picture. If the controller
button is not configured yet, use Steam's on-screen Enter Big Picture Mode
command to test the mode itself.

Then run the project configurator, select displays and audio outputs, create and
apply the setup kit, and test a complete session. Give the automation a few
seconds after entering and leaving Big Picture.

Checklist:
- Steam is installed, signed in, and running.
- The controller is connected and visible to Steam.
- Your TV is selected as the preferred Big Picture display.
- Steam startup with Windows is enabled only if desired.
- Steam's direct startup into Big Picture is disabled for the controller-first
  flow.
