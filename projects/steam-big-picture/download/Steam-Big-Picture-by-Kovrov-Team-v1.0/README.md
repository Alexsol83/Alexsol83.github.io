# Steam Big Picture by Kovrov Team

Автоматизация для Windows: при запуске Steam Big Picture переключает выбранные дисплеи и аудиовыходы, а после выхода восстанавливает рабочую конфигурацию.

## Требования

- Windows 10/11 с Windows PowerShell 5.1 и .NET Framework 4.x.
- Скачайте **MultiMonitorTool** и **SoundVolumeView** отдельно с сайта [NirSoft](https://www.nirsoft.net/) и положите их EXE-файлы рядом с мастером настройки. Это сторонние утилиты NirSoft, они не созданы Kovrov Team и не входят в этот ZIP. Ознакомьтесь с лицензией и условиями использования.
- Для физического управления питанием дисплея требуется поддержка DDC/CI.

## Файлы проекта

- `Steam Big Picture by Kovrov Team.exe` — запускатель мастера настройки.
- `Configurator.ps1` — мастер Windows Forms и сборщик установочного комплекта.
- `SteamBigPictureLauncher.cs` — исходный код запускателя на C#.
- `BuildProgram.bat` — сценарий пересборки в Windows с компилятором .NET Framework.
- `Steam-Setup-Guide.txt` — публичная инструкция по подготовке Steam.
- `README.md` — этот файл.

## Установка и настройка

1. Распакуйте ZIP в отдельную папку.
2. Скачайте две утилиты NirSoft отдельно и положите их EXE-файлы рядом с запускателем.
3. Запустите `Steam Big Picture by Kovrov Team.exe`.
4. Обновите список устройств, выберите дисплеи и аудиоустройства для ролей Console, Multimedia и Communications.
5. Создайте установочный комплект, затем запустите `ApplySetup.cmd` из созданной папки. Steam должен быть установлен и хотя бы один раз запущен.

Установщик сохраняет копии заменяемых файлов, устанавливает автоматизацию в `C:\Tools\MultiMonitorTool` и добавляет автозапуск для текущей учётной записи Windows.

## Работа во время сеанса

При входе в Big Picture автоматизация делает короткую паузу, выключает выбранные дисплеи и переключает звук. При выходе она включает дисплеи и восстанавливает аудиоустройства Windows, сохранённые до сеанса. Журнал записывается в `C:\Tools\MultiMonitorTool\SteamBigPicture.log`.

## Резервная копия и конфиденциальность

Храните созданный `SteamBigPicture-ConfiguredKit.zip` в личной резервной копии. В нём содержатся настройки устройств, поэтому не публикуйте его. После переустановки Windows установите и запустите Steam, установите зависимости NirSoft отдельно и примените сохранённый комплект. Он предназначен для конкретной учётной записи Windows и конфигурации оборудования. Чтобы отменить установку, восстановите заменённые файлы из резервной копии установщика и удалите созданную запись автозапуска.

Названия и идентификаторы устройств могут измениться после замены оборудования. При необходимости запустите мастер повторно. Архив не содержит персональных настроек устройств.
