01 / Обзор

Один EXE — готовый сценарий

Приложение включает мастер настройки, установочные сценарии и утилиты NirSoft. Пользователь выбирает дисплеи и одно аудиоустройство, затем применяет параметры прямо из программы — отдельная сборка установочного комплекта не нужна.

Выбор устройств

Мастер показывает подключённые мониторы и устройства вывода звука для выбора игровой конфигурации.

Применение из приложения

После подтверждения Windows UAC программа устанавливает автоматизацию и настраивает её запуск для текущей учётной записи.

Автоматический возврат

При выходе из Big Picture приложение включает выбранные дисплеи и восстанавливает прежний звук.

03 / Подготовка

Настроить Steam и применить параметры

  1. Установить Steam, войти в аккаунт и оставить клиент запущенным в Windows.
  2. Подключить контроллер и проверить, что Steam его распознаёт.
  3. Выбрать телевизор предпочтительным экраном для Big Picture в настройках Steam.
  4. При необходимости включить запуск Steam вместе с Windows; для сценария с контроллером не включать прямой запуск Big Picture.
  5. Запустить EXE и подтвердить запрос Windows UAC.
  6. Обновить список устройств, выбрать дисплеи и один аудиовыход, нажать «Применить настройки» и проверить вход/выход из Big Picture.

Названия пунктов Steam могут меняться между версиями клиента. Полная памятка доступна в разделе «Подготовка Steam».

04 / Реализация

Самодостаточная установка и возврат настроек

Как устроено

  • Приложение на C# включает мастер PowerShell и необходимые ресурсы.
  • Утилиты MultiMonitorTool и SoundVolumeView встроены в EXE, их не нужно устанавливать отдельно.
  • После выбора устройств приложение устанавливает сценарии и добавляет автозапуск для Windows.
  • Требуются Windows PowerShell 5.1 и .NET Framework, обычно уже доступные в Windows.

Восстановление

  • Автоматизация сохраняет резервные копии и возвращает предыдущие настройки звука и дисплеев.
  • Кнопка «Вернуть» отключает автозапуск и удаляет папку C:\Tools целиком, включая резервные копии.
  • Перед нажатием «Вернуть» сохраните нужные данные из C:\Tools.
  • Инструкция и уведомление NirSoft доступны на этой странице и в архиве.
