README проекта

Steam Big Picture by Kovrov Team — утилита для Windows, которая автоматически переключает выбранные дисплеи и аудиовыходы при запуске Steam Big Picture и восстанавливает их после выхода.

Возможности

  • Находит подключённые мониторы и устройства воспроизведения в мастере Windows Forms.
  • Создаёт установочный комплект для выбранных дисплеев и аудиоролей Console, Multimedia и Communications.
  • При запуске Big Picture делает короткую паузу, выключает выбранные мониторы и переключает аудиовыходы.
  • При выходе снова включает выбранные мониторы и восстанавливает прежние аудиоустройства Windows.

Требования

  • Windows 10/11 с Windows PowerShell 5.1 и .NET Framework 4.x.
  • MultiMonitorTool и SoundVolumeView от NirSoft. Их нужно скачать отдельно и положить рядом с мастером.
  • Поддержка DDC/CI дисплеем, если требуется физическое управление питанием монитора.

Сторонние зависимости: MultiMonitorTool.exe и SoundVolumeView.exe — утилиты NirSoft, они не созданы командой Kovrov Team и намеренно не включены в ZIP. Скачивайте их с сайтов MultiMonitorTool и SoundVolumeView и ознакомьтесь с условиями использования.

Файлы в архиве

  • Steam Big Picture by Kovrov Team.exe — запускатель мастера настройки.
  • Configurator.ps1 — мастер выбора устройств и сборки установочного комплекта.
  • SteamBigPictureLauncher.cs — исходный код запускателя на C#.
  • BuildProgram.bat — сценарий пересборки в Windows с компилятором .NET Framework.
  • Steam-Setup-Guide.txt — публичная инструкция по подготовке Steam.
  • README.md — описание проекта и установки.

Установка и настройка

  1. Скачайте ZIP и распакуйте в отдельную папку.
  2. Отдельно скачайте две утилиты NirSoft и положите их EXE-файлы рядом с запускателем.
  3. Запустите Steam Big Picture by Kovrov Team.exe.
  4. Обновите список устройств, выберите дисплеи и назначьте устройства для ролей Console, Multimedia и Communications.
  5. Создайте установочный комплект и запустите ApplySetup.cmd из созданной папки. Steam должен быть установлен и хотя бы раз запущен.

Установщик сохраняет резервные копии заменяемых файлов, устанавливает автоматизацию в C:\Tools\MultiMonitorTool и добавляет автозапуск для текущей учётной записи Windows.

Резервная копия и восстановление

Храните созданный SteamBigPicture-ConfiguredKit.zip в личной резервной копии. Внутри находятся настройки выбранных устройств; архив предназначен для конкретного компьютера и не должен публиковаться. После переустановки Windows установите и запустите Steam, скачайте зависимости NirSoft отдельно и примените сохранённый комплект. Чтобы отменить установку, восстановите заменённые файлы из резервной копии установщика и удалите созданную запись автозапуска.

Примечания

Названия и идентификаторы устройств привязаны к компьютеру и могут измениться после смены оборудования. При необходимости запустите мастер повторно. В публичном архиве нет персональной конфигурации устройств.
