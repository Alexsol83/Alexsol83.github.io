Windows Automation

Набор практических PowerShell/VBS-сценариев для автоматизации устройств, запуска программ, мониторов и звука.

PlatformWindows
CorePowerShell
StartupVBS / Registry
ToolsMultiMonitorTool · SoundVolumeView

Подход

  • Определить текущее состояние системы.
  • Выполнить действие над нужными устройствами.
  • Сохранить и восстановить состояние, когда это необходимо.
  • Убрать повторяющиеся ручные действия из ежедневного сценария.

Результат

Небольшие скрипты превращают повторяющиеся настройки Windows в автоматические и воспроизводимые сценарии.
