Windows Automation

Набор практических PowerShell/VBS-сценариев для автоматизации Windows: мониторы, аудио, запуск и поведение программ.

ЯзыкPowerShell
АвтозапускVBS / Windows startup
УстройстваMultiMonitorTool · SoundVolumeView
ЦельМинимум ручных действий

Принцип

  • Определить нужное состояние системы.
  • Выполнить действие над устройствами.
  • Сохранить/восстановить состояние там, где это необходимо.
  • Запускать сценарий автоматически при входе в Windows.

Результат

Небольшие сценарии превращают повторяющиеся настройки Windows в один автоматический процесс.
