04 / PROJECT

Pyrus / SLA Dashboard

Проработка ИТ-процесса: этапы обработки задач, старт и стоп SLA, сроки, возвраты и показатели для единого дашборда.

СистемаPyrus
МетрикиSLA · объём задач · просрочки
ПроцессРабота с ВСП
ФорматDashboard / единые метрики

Что измеряется

  • Количество поступивших и выполненных задач.
  • Соблюдение SLA по этапам.
  • Просроченные задачи.
  • Возвраты и повторная обработка.

Результат

Процесс переводится из ручного контроля в понятную систему метрик, которую можно использовать для оперативного управления нагрузкой и качеством сервиса.
